# Dino Lab

A lightweight, browser-based obstacle avoidance experiment inspired by Chrome Dino.

The autonomous bot navigates obstacles using noisy and delayed sensor readings while dealing with wind disturbances and limited battery capacity.

### Features
- Rule-based autonomous obstacle avoidance
- Noisy sensors, delayed readings, and missed detections
- Wind disturbances and battery constraints
- Sensor View for visualizing the bot's observations
- CSV telemetry export for analysis in PlotJuggler
- Fully client-side, offline-capable, with no external dependencies

### Future Work
Explore reinforcement learning to train an obstacle avoidance policy through repeated simulated runs, and compare its performance against the existing rule-based controller.
